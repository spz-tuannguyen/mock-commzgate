Tài Liệu Tích Hợp & Mẫu Code Gọi API

Thay thế URL CommzGate thật trong dự án của bạn bằng URL của Mock Server này.

Danh Sách Endpoints Được Hỗ Trợ:

Chế Độ Method Đường Dẫn Endpoint Mô Tả & Tham Số Chính
Cloud GET / POST /gateway/SendMessage Gửi SMS Cloud: ID, Password, Mobile, Type, Message, OTP
Cloud GET / POST /gateway/SendMessage.aspx Tương thích các thư viện legacy .NET của Commzgate
Device GET / POST /api/SendMsg hoặc /SendMsg Gửi SMS CG-ONE: token, mobile, message, otp
Device GET / POST /api/GetMsgStat Kiểm tra trạng thái tin nhắn modem: id, token

Mẫu Code Gọi API:

// 1. Commzgate Cloud:
var client = new HttpClient();
var cloudUrl = "https://your-mock-url.com/gateway/SendMessage?ID=my_id&Password=my_pass&Mobile=6591234567&Type=A&Message=Hello+World&OTP=true";
var response = await client.GetAsync(cloudUrl);
string result = await response.Content.ReadAsStringAsync();
// Kết quả: STATUS=000:SUCCESS:ID=CGM12345678,OTP=682910

// 2. Commzgate Device (CG-ONE Appliance):
var deviceUrl = "https://your-mock-url.com/api/SendMsg?token=cg_token_secret&mobile=6591234567&message=Alert+from+CG-ONE";
var devResponse = await client.GetAsync(deviceUrl);
string devResult = await devResponse.Content.ReadAsStringAsync();
// Kết quả: CG1083921
